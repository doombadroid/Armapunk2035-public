# 🎪 Project LooneyBin — Feature List

**Asylum-style Altis Life, rebuilt and rebranded.** Here's what's live:

## 🆕 New & Unique
- **Placeable home furniture** — buy furniture at the **Homegoods Store** in your house menu, place it anywhere in your house (beds, desks, TVs, gaming setups, fridges, more), rotate + height-adjust, lie down on beds. Persists across restarts; pick it back up any time.
- **Custom car horns** — EFN, Randy Marsh, Not a Big Fan, RIP George, Whopper, Tornado Siren + more.
- **Ultimate Healing Sunshine Love Bomb** (TT) — the ultimate retirement-party send-off. 💥
- **Revive drones** for medics — fly a UAV out and revive/treat from the air.

## 🚔 Police (MaxSec)
- Ranks Cadet → Chief, full prestige + talent trees
- Arrest / restrain / escort / jail / ticket / wanted list / warrants / APB
- Search & seizure, evidence vault, deployables, spike strips, non-lethal, radar/speed cams
- **Live dispatch alerts** — auto-pings to on-duty officers on bank drills, Fed Reserve, prison breaks, store robberies (with map markers)
- **MaxTac deployment** — summons popup + join action → MaxTac kit + MRAP drop
- Marked + undercover vehicles, Mobile HQ, service chopper, impound

## 🚑 Medic (TT)
- Ranks EMR → Chief + prestige tree
- Revive, bloodbag, FAK, adrenaline, painkillers, rehab
- **Revive drones**, mobile medical shop, repair-building jobs
- **Firefighter system** — hose + gallons, axe, building fires
- Earn cash + XP for revives

## 🧑 Civilian
- **Gangs** — create/invite/ranks, gang house + garage, gang bank, talents, **gang wars**, fortress
- **Bounty Hunter** — Vigilante → Master BH, Honor/Skiptracer, track + capture + turn-in
- **Rebel** — Infamy tree, rebel weapons/vehicles/license
- **Heists** — bank robbery (drill/safe/vault/lighthouse), Federal Reserve, Jewelry Emporium, Evidence Vault, store/convoy/person robbery, gas stations
- **Drugs** — cannabis, heroin, cocaine, meth/crank/LSD/PCP; drug runner (ground + air); moonshine; effects/addiction/overdose/rehab
- **Industry** — mining (copper/iron/diamond/gold/uranium/salt/sand), oil, fishing, fungi, hunting, wood, metal detector + treasure hunt
- **Delivery missions** — ground + air
- Justice — jail, bail, prison break

## 💀 Cartels & Turf
- **Cartels** — Arms / Drug / Oil / Wong's — capture + hold for perks (gather speed, robbery payouts, black-market discounts)
- **Turf wars** — capture turf, turf dealers/shops, turf tax

## 💰 Economy & Property
- Cash / bank / New Drachma, paychecks, ATM, wire transfer, debit card
- Shops — general, weapon, vehicle, clothing, virtual goods; dynamic cartel-driven market
- **Houses** — buy, storage, upgrade, keys/holders, lock, tax, aging barrel, **+ furniture (above)**
- **Player Exchange** — player-to-player market listings
- Garage / impound / keys / lockpick / repair / refuel / chop shop

## 🌍 World
- Day/night + weather, seasonal events (Christmas, Easter)
- Phone hub, licenses/DMV, duel arena, lottery, UFO crash event, protest, camp fire, passive mode, tutorial
- Daily login bonus
- 110+ criminal charges

## 🤖 Discord Bot (loonybot)
- **!report** — bug/exploit + player reports via DM wizard → private staff thread
- **!link** — link Discord ↔ in-game (one-time **500k** bank bonus)
- Admin console — server restart/msg/kick/ban, whitelist, comp
